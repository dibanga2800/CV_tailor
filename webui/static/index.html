        Database

        Checking…

        With PostgreSQL connected, everything the app keeps about you is saved there: master CV and facts, skills bank, projects, tailored CVs and versions, jobs and statuses, applications and outcomes, interview packs, and the tracker. The files in your documents folder stay as a working copy and are kept in step both ways, so Claude Code's /apply still works and a lost folder is rebuilt from the database on the next start.

        Setting up PostgreSQL on Windows
        1. Install PostgreSQL from postgresql.org/download/windows (or winget install PostgreSQL.PostgreSQL.17). Set a password for the postgres user and keep port 5432.
        2. Open "SQL Shell (psql)" from the Start menu, log in as postgres, and run these two lines one at a time, with your own password:
          CREATE USER cvtailor WITH PASSWORD 'choose-a-password';
          CREATE DATABASE cvtailor OWNER cvtailor;
        3. Paste postgresql://cvtailor:choose-a-password@localhost:5432/cvtailor above (with your password) and click Test and connect. The app creates its tables and copies your existing data in.
        Query it (SQL, Power BI)

        Tables, refreshed as you work: cvt_jobs (job list and statuses), cvt_applications (the tracker), cvt_application_events (each interview, offer or rejection with its date), cvt_facts (your fact bank). cvt_files holds the stored files themselves. Read them freely; let the app do the writing.
